Fast & Easy Setup

How to Install SocialShare in 60 Seconds

Works seamlessly on Google Chrome, Brave, Microsoft Edge, and Arc Browser. No Developer account required.

01

Download & Unzip

Click the download button to get social-extension.zip. Right-click the downloaded file and select "Extract All" (or Unzip) into a folder on your computer.

Download ZIP File
02

Open Extensions Page

In your browser address bar, open the extensions manager page:

chrome://extensions
03

Enable Developer Mode

In the top-right corner of the Extensions page, switch the Developer mode toggle to ON.

💡 This enables the "Load unpacked" button for local extensions.
04

Click "Load Unpacked"

Click the "Load unpacked" button in the top-left corner, and select the unzipped social-extension folder (the folder containing manifest.json).

Done! SocialShare will appear in your extensions list.
📌
Pro-Tip: Pin SocialShare for 1-Click Access

Click the puzzle piece icon (🧩) in Chrome's top-right toolbar and click the pin icon next to SocialShare so it's always one click away while browsing any article!
